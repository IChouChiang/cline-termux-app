# Cline Termux changelog

## 0.1.0-pre.2

- An answer that you saw in the open chat stays read after a force stop and a cold start of the app.
- The stop notice after the mistake limit is the last row of its turn and shows no mistake count.
- On **Keep the kernel running**, an item with the status **Done** shows no button and does not expand.
- When the active Hub is older than the installed port, **Settings** > **Kernel** shows **Restart to use** and the new release.
- The header of the sessions drawer shows the app name without the logo.

## 0.1.0-pre.1

- First public prerelease: chat with the Cline kernel in Termux from a native Material 3 app, with streaming replies, Markdown and the full tool transcript.
- Approve tool calls and answer Cline's questions in a sheet (a notification takes you there while the app is in the background), and steer or queue follow-up prompts while Cline works.
- Review uncommitted changes and tool output, restore a session to an earlier checkpoint, and fork a whole session.
- Sign in with Cline or connect any provider with an API key, and pick the model and thinking level per session.
- Customize tools, plugins, skills, rules, _Model Context Protocol_ (_MCP_) servers and hooks, and install more from the marketplace.
- Run routines on a schedule inside the Cline Hub and follow every subagent a task starts.
- Check the kernel's health, restart it, and export diagnostics to attach to an issue.
