# Cline Termux 0.1.0-pre.1

Version 0.1.0-pre.1 is the first public prerelease of Cline Termux, for testers.
Cline Termux is an unofficial Android app for the Cline _command-line interface_ (_CLI_) in Termux.
Cline Termux is not affiliated with or endorsed by Cline Bot Inc. or the Termux project.
Report problems with this app on the [Issues](https://github.com/IChouChiang/cline-termux-app/issues) page of the app repository, not to Cline or Termux.

## Prepare your phone

- Android 8.0 (API level 26) or later.
- Termux 0.109 or later, from F-Droid or GitHub.
- The cline-termux port (https://github.com/IChouChiang/cline-termux), release 3.0.68-termux.2 or later.
  Use the latest release of the port.

For the setup steps, see `README.md` in this repository.

## Review what works

The release notes on the **About** screen of the app show the same list.

- First public prerelease: chat with the Cline kernel in Termux from a native Material 3 app, with streaming replies, Markdown and the full tool transcript.
- Approve tool calls and answer Cline's questions in a sheet (a notification takes you there while the app is in the background), and steer or queue follow-up prompts while Cline works.
- Review uncommitted changes and tool output, restore a session to an earlier checkpoint, and fork a whole session.
- Sign in with Cline or connect any provider with an API key, and pick the model and thinking level per session.
- Customize tools, plugins, skills, rules, _Model Context Protocol_ (_MCP_) servers and hooks, and install more from the marketplace.
- Run routines on a schedule inside the Cline Hub and follow every subagent a task starts.
- Check the kernel's health, restart it, and export diagnostics to attach to an issue.

## Review the known limits

The IDs in parentheses refer to `docs/decided.md` and to the trial log in `docs/todo.md`.
U1 to U10 are kernel issues that this project plans to report to upstream Cline.
`README.md` gives more detail and the recovery steps.

- The app has no `/compact` command, because the Hub has no command for manual compaction (U3).
- If a session used hooks in the `cline` terminal, a later turn from the app can wait forever (U2).
- If a `PreToolUse` hook cancels a tool call, the kernel stops the whole turn (U5).
- Sessions that you start with `cline -z` (zen mode) never compact automatically (U8).
- Automatic compaction starts too early, because the kernel counts each attached image as text (U9).
- If the model sends an empty summary, the kernel skips compaction and tries again at each turn (U10).
- After the first compaction, the kernel can compact again after every five large tool results (U7).
- The app restores a checkpoint in two separate kernel steps, because the one-step restore loses a stored API key (U1).
- The app cannot show recovery notices, because the kernel does not send recoverable errors to clients (U6).
- The slash menu does not show plugin commands, because no Hub command lists plugin commands.
- After you upgrade the port, the old Hub can stay active until you restart the Hub (row 24).
- The project has not tested agent teams from the app yet. If the **Teams** tool is off, the app does not start agent teams.
- **Plan** and **Act** in the composer change only the prompt, not the tools of the session.
- While the mistake-limit question waits for an answer, the model calls continue for up to five minutes (A17).
- If dictation shows a language error, install the offline speech pack for your phone language (A7).
- After a force stop and a cold start, a session can show **Unread** for an answer that you saw (row 20).
- The stop notice after the mistake limit is not always the last row of the turn (row 21).
- When you open the **Cline battery** item with the status **Done**, the item still shows **Allow** (row 22).
- The project has not tested **Sign in with Cline** with a real Cline account yet (B8.1).
- The project has not tested tablet layouts and other wide layouts on a device yet (B8.2).

## Install this prerelease

1. Download the _Android package_ (_APK_) file from the **Releases** page of this repository.
2. Open the APK file on your phone.
   If Android asks, allow your browser or file manager to install unknown apps.
3. Tap **Install**.

The release key of the project signs this APK.
The SHA-256 digest of the signing certificate is:

```
1c5867e1aa40a3760a3707c6c1c25f0330810ad8a86a0c3d3d5d08d4b6c0873c
```

To verify the digest, follow "Verify the APK signature" in `README.md`.
Later prereleases use the same key, so a later prerelease installs over this prerelease and keeps your app data.

If you installed a release build of this app that you made yourself, uninstall that build first.
When you uninstall the app, Android deletes the app data.
Your sessions stay in Termux.
